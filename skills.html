Add-ons — one command each

Layer On More

Optional skills you install from Claude Code. Compatible with NanoClaw and OpenClaw skill ecosystems.

How to install an add-on

Terminal — inside your GhostClaw directory
$ claude
# then in Claude Code:
> /add-gmail-agent # or whichever skill
/add-gmail-agent
Gmail read/send. Verification codes, urgent flags, summaries. Full email agent loop.
$ /add-gmail-agent
/add-voice-transcription
Voice note transcription via ElevenLabs. Send a voice message, get text back. Talk to your bot.
$ /add-voice-transcription
/add-voice-reply
Bot replies with voice notes via ElevenLabs TTS. Full two-way voice conversation loop.
$ /add-voice-reply
/add-heartbeat
Periodic health checks — disk, logs, services. Silent unless something needs your attention.
$ /add-heartbeat
/add-morning-briefing
Daily or weekly briefings sent to Telegram. Whatever you want to know when you wake up.
$ /add-morning-briefing
/add-slack
Slack as an additional channel. Socket Mode, no public URL needed. Runs alongside Telegram.
$ /add-slack
/add-telegram-swarm
Multi-bot agent teams in Telegram. Each sub-agent gets its own bot identity and personality.
$ /add-telegram-swarm
/add-update-check
Weekly check for new GhostClaw releases. Notifies you in Telegram when there's an update to pull.
$ /add-update-check
/add-namecheap
Domain availability search via Namecheap API. Check and register domains without leaving your terminal.
$ /add-namecheap

more skills drop regularly. watch the repo.

Claude Code skills — what the agent builds with

Builder Skills

Skills that extend Claude Code itself — loaded as slash commands, they change how the agent approaches tasks. Built by the GhostClaw team.

How to install a Claude Code skill

Terminal
# Clone the skill repo into ~/.claude/skills/
$ git clone https://github.com/b1rdmania/[skill-repo] ~/.claude/skills/[skill-name]
# Then use it in Claude Code:
> /skill-name # runs the skill
Brand Audit
